# 교통 API · 시각화 가능 여부 (러프)

> 목적: 기획 검토용. 구현 상세·연동 스펙은 다루지 않음.

---

## 1. 지하철 노선도

### 결론

**가능.** 공개 API로 역·노선·경로 **데이터**를 받아 **자체 시각화**하는 방향으로 잡으면 된다.  
완성된 노선도 이미지/타일을 그대로 주는 API는 기대하지 않는다.

### 가능 여부

| 목적 | 가능 | 비고 |
|------|:----:|------|
| 노선·역 목록으로 그래프/노선도 그리기 | O | 역·호선 데이터로 충분 |
| 출발→도착 경로 하이라이트 | O | 최단경로 API 활용 |
| 완성된 노선도 이미지/타일 수신 | X | 데이터만 제공 |
| 역 좌표 기반 지도 위 표시 | △ | 좌표 데이터셋 필요. 노선 곡선은 별도 자산일 수 있음 |

### 참고 데이터 소스

- 서울교통공사 노선별 지하철역 정보 (열린데이터광장 / 공공데이터포털)
- 서울교통공사 최단경로이동정보
- 국가철도공단 도시철도 전체노선정보 (전국)

## 2. 경기도 버스 시간 조회

### 결론

**가능.** [경기버스정보 Open API](https://www.gbis.go.kr/) / [공공데이터포털](https://www.data.go.kr/data/15080346/openapi.do) 로 조회 가능.  
다만 “시간”의 의미가 **실시간 도착** vs **첫·막차·배차간격** 인지에 따라 쓰는 API가 다르다.  
분 단위 전체 운행 시각표(전 회차 리스트)는 공개 API만으로는 **제한적**일 수 있다.

### 가능 여부

| 목적 | 가능 | 비고 |
|------|:----:|------|
| 정류소별 실시간 도착 예정 | O | 버스도착정보 조회 (predictTime 등) |
| 노선 첫차·막차·배차간격 | O | 노선정보 항목조회 (평일/토/일/공휴일) |
| 노선·정류소 목록 / 경유정류소 | O | 노선·정류소 조회 서비스 |
| 노선 형상(지도 위 라인) | O | 노선 형상정보 조회 → 시각화에 유리 |
| 전 회차 분 단위 고정 시간표 | △ | 공개 API 중심으론 첫·막차+배차간격에 가깝음 |

### 참고 데이터 소스

- 경기도_버스도착정보 조회 (공공데이터포털)
- 경기도 버스노선 / 정류소 조회 서비스 (경기버스정보 공유서비스)
- 인증키: 공공데이터포털 발급

### 조회 흐름 (러프)

1. 노선번호 → `routeId`
2. `routeId` → 경유 정류소 / 첫·막차·배차
3. `stationId` (+ `routeId`) → 실시간 도착

## 공통 기획 전제

- **커스텀 시각화**: API 데이터 → 그래프/캔버스/지도 레이어로 직접 그림
- **인증키** 필요. 트래픽·갱신주기는 기관 정책에 따름
- **비범위(러프 단계)**: 공식 노선도/노선맵 그래픽 API, 전국 버스 단일 API 통합 등
