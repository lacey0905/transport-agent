# 앱이 알아야 하는 정보

판교 출퇴근 최적 경로 앱의 **현장 기준값**.  
경로 계산·UI는 이 숫자를 전제로 한다.

코드 매핑: `src/constants/commute.ts`

---

## 출근

집 → 경강선 → 판교역 → 버스/셔틀 → 네오위즈

| 구간 | 시간 | 비고 |
|------|:----:|------|
| 집 → 경강선 승강장 | **10분** | 도보 |
| 판교역 → 버스 정류장 | **5분** | 도보. 대기와 겹치면 차감 |
| 버스 → 네오위즈 | **10분** | 380 · 셔틀 · 602-2B **일괄** |

```
집 ──10분──▶ 경강선 승강장 ──열차──▶ 판교역 ──5분──▶ 정류장 ──10분──▶ 네오위즈
```

- 탑승 후보: **380**, **셔틀**, **602-2B**
- 같은 도착이면 우선순위: 380 > 셔틀 > 602-2B
- 출근 정류장: **판교역서편** (380 · 602-2B)

---

## 퇴근

네오위즈 → 버스/셔틀 → 판교역 → 경강선

| 구간 | 시간 | 비고 |
|------|:----:|------|
| 사무실 → 버스 정류장 | **5분** | 도보. 대기와 겹치면 차감 |
| 출구 → 버스 정류장 | **1분** | 도보. 대기와 겹치면 차감 |
| 버스 → 판교역 | **10분** | 380 · 셔틀 **일괄** |
| 판교역 → 경강선 승강장 | **5분** | 도보. 대기와 겹치면 차감 |

```
사무실 ──5분──▶ 정류장 ──10분──▶ 판교역 ──5분──▶ 경강선 승강장
출구    ──1분──▶ 정류장 ──10분──▶ 판교역 ──5분──▶ 경강선 승강장
```

- 탑승 후보: **380**, **셔틀** (**602-2B 제외**)
- 퇴근 정류장: **판교환경생태학습원** (380)
- 목표: 가장 빠른 경강선을 **여유 1분** 두고 탑승

---

## 도보와 대기

다음 차까지 남은 시간 ≥ 도보 시간이면, 걷는 동안 차가 오므로 **도보를 따로 더하지 않는다.**

예: 버스 8분 뒤, 도보 5분 → 지금 출발해도 되고, 실효 도보는 0.

---

## 출발 기준

- 화면 큰 시계는 현재 시각이다. **집 / 판교역 / 사무실 / 출구를 누르면 그 시각으로 멈춘다.**
- 멈춘 뒤에는 시계를 눌러 **휴대폰 기본 시간 UI**로 출발 시각을 바꿀 수 있다.
- 같은 버튼을 다시 누르면 해제되고 시계가 흐른다. 다른 버튼을 누르면 그쪽으로 바뀐다.
- **15:00 전**에는 집·판교역만, **15:00부터**는 사무실·출구만 누를 수 있다.
- **집**: 집에서 출발 (판교역에 아직 없음)
- **판교역**: 이미 판교역에 있음
- **사무실**: 퇴근, 정류장까지 5분
- **출구**: 퇴근, 정류장까지 1분
- 그 시각부터 도보·셔틀·경강선을 맞춘다.
- 화면에 보여주는 건 **추천 경로 하나**뿐이다.
- 버스 도착만 1분마다 최신값으로 다시 맞춘다.

## 셔틀 · 경강선

셔틀 시각표는 [shuttle-bus.md](./shuttle-bus.md). 이동은 위 표의 **10분**을 쓴다.

- 출근: 08:05 ~ 10:05, 15분 간격
- 퇴근: 17:00 ~ 21:00, 20분 간격

경강선은 **평일 정적 시각표**. 주말·공휴일·지연은 반영하지 않는다.
